# ZuusTweaks
- Personal plugin for any servers I make. Various QOL features and Server Spawn stuff.
- I don't view this plugin worthy enough to added around Bukkit and Modrinth.


## Features
All features can be toggled and adjusted.
- Droppable Ender Chests.
- Insta-Kill Withers to prevent lag/griefing.
- Unbreakable Anvils
- Limited Trees (Saplings don't drop)
- Basic Anti-Lava Casting

## Server Spawn Features
Various perks for the world center. Can be added for any world in config.
- Speed Boost
- Anti-Break/Place
- No Lava/Water Flow
- No Explosions (Currently vulnerable to explosions near the edge of protected area.)
- No Player Damage
- No Player Hunger
- No Harm to Mobs/Named Mobs
- No Monster Agro
